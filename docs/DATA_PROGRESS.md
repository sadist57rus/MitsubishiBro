## Правила учёта

- Строка соответствует записи модели в `vehicleCatalog.ts` после импорта базового и расширенного каталога и дедупликации.
- Одинаковые поколения с разными ID пока не объединяются: сначала отдельная проверка идентичности и дублей.
- «% подтверждённых полей» считается только по полям конкретной модификации, для которых сохранена проверяемая ссылка и область применимости; на этапе 0 значения не исследовались и показатель равен 0%.
- `needsHumanReview = true` до проверки первичного источника и идентификации точной модификации.
- «Конфликты» = «не проверены» до сопоставления значений; это не означает, что конфликтов нет.
- PR создаётся на одну модификацию. На этапе 0 PR на технические данные не создавались.

## Обнаруженные пробелы и дубли каталога

- В каталоге обнаружено 36 записей Toyota/Mitsubishi с учётом ID; дополнительно отмечены 3 запрошенные модели, которых в текущем каталоге нет. Часть имеющихся записей описывает одно и то же поколение/кузов. Сохранять отдельные ID в очереди до отдельного решения о дедупликации.
- Mitsubishi L200, Mitsubishi ASX и Toyota Land Cruiser 200 не найдены в текущем наборе записей `vehicleCatalog.ts` после импорта расширений. Их нельзя включить в работу по данным, пока не добавлены модели в отдельном согласованном изменении.
- Даты/кузова выше — только метаданные текущего каталога, а не независимо подтверждённые годы производства. Их проверка — часть следующего этапа.
- Сначала пилот: Outlander II / CW5W / 4B12. Нужны точный рынок и диапазон модельных лет до подбора руководства.

## План рынков и первичных источников

Рынки учитываются раздельно; сведения из одного региона не переносятся в другой.

1. **Россия / СНГ** — приоритет для пользовательского спроса. Для Mitsubishi стартовая точка: https://www.mitsubishi-motors.ru/for-mitsubishi-owners/manuals/ . Для Toyota требуется найти официальный региональный архив/документ для точной модели; общий сайт не считается подтверждением.
2. **Япония** — Toyota: https://manual.toyota.jp/ ; Mitsubishi: https://www.mitsubishi-motors.co.jp/afterservice/manual/ . Японские спецификации применяются только к соответствующим японским модификациям.
3. **Европа** — Mitsubishi: https://www.ownersmanual.mitsubishi-motors-europe.com/ ; для Toyota необходимо подобрать официальный региональный портал и конкретное руководство.
4. **Северная Америка (США/Канада)** — Toyota: https://www.toyota.com/owners/warranty-owners-manuals/ ; Mitsubishi: https://parts.mitsubishicars.com/ для OEM-каталога и https://www.mitsubishitechinfo.com/epacarb/svcoverview.jsp для сервисной информации. Каталог деталей не заменяет сервисное руководство.

### Доступность первичных источников: предварительный реестр

На этапе 0 не заявляется, что какой-либо конкретный документ уже недоступен: проверка доступности выполняется для выбранной модификации на этапе 1. До такой проверки остаются **неподтверждёнными по доступности**:

- заводские сервис-мануалы для старых/снятых с производства моделей на точный рынок и код кузова;
- VIN/номер-рамы EPC для OEM-артикулов и цепочек замен деталей;
- сервисные порталы Mitsubishi/Toyota, если нужная процедура открывается только после регистрации, подписки или через дилера;
- официальные графики ТО для конкретного рынка/модельного года, если они не опубликованы в руководстве владельца.

Если первичный источник окажется платным, закрытым или отсутствующим, это будет зафиксировано как ограничение; работа по критичным значениям остановится до согласования. Зеркала сервис-мануалов и форумы не будут использоваться как замена официальному первичному источнику для статуса `verified`.

### Результат первичной проверки доступности порталов (2026-10-19)

- Toyota Japan owner manuals: https://manual.toyota.jp/ — официальный каталог руководств владельца найден; наличие конкретного документа нужно проверять по модели/периоду. Это не гарантирует доступ к заводскому repair manual.
- Toyota Japan repair manuals/wiring diagrams: https://toyota.jp/faq/ — официальный сайт сообщает, что ремонтная документация (включая руководства по ремонту и электросхемы) предоставляется по лицензии. Считать потенциально платным источником и остановиться, если критичное поле требует такой документации без доступной лицензии.
- Toyota USA manuals: https://www.toyota.com/owners/warranty-owners-manuals/ — официальный портал доступен; он ориентирован на американские модель/год и не доказывает спецификации других рынков.
- Toyota USA TIS: https://techinfo.toyota.com/techInfoPortal/appmanager/t3/ti?_nfpb=true&_pageLabel=ti_toy_lib_content — библиотека сервисной документации существует; доступ и применимость к конкретному рынку/модификации нужно подтвердить отдельно.
- Mitsubishi Russia manuals: https://www.mitsubishi-motors.ru/for-mitsubishi-owners/manuals/ — официальный сайт содержит отдельные годы руководств для части моделей (в том числе отдельные годы ASX/Outlander/Pajero Sport); для старых модельных лет из очереди наличие нужного руководства пока не подтверждено.
- Mitsubishi Europe owner manuals: https://www.ownersmanual.mitsubishi-motors-europe.com/ — официальный портал указывает охват начиная с модельного года 2025 и направляет за руководствами старых моделей к дилеру. Поэтому он не подтверждает покрытие старых Outlander/Lancer/Pajero.
- Mitsubishi North America service information: https://www.mitsubishitechinfo.com/epacarb/svcoverview.jsp — официальный портал прямо требует регистрацию и подписку для доступа к сервисным руководствам и бюллетеням. Если необходимое значение можно подтвердить только там, требуется доступ по подписке; без него поле остаётся `null`/частично подтверждённым.

Это результаты проверки порталов, а не утверждение о наличии конкретных руководств для CW5W/4B12. До этапа 1 ни одна техническая величина не подтверждена.
