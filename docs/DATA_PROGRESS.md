# Прогресс проверки данных Car Brother

Дата создания: 2026-10-19. Ветка подготовки: `docs/data-verification-stage-0`.

## Правила учёта

- Строка соответствует записи модели в `vehicleCatalog.ts` после импорта базового и расширенного каталога и дедупликации.
- Одинаковые поколения с разными ID пока не объединяются: сначала отдельная проверка идентичности и дублей.
- «% подтверждённых полей» считается только по полям конкретной модификации, для которых сохранена проверяемая ссылка и область применимости; на этапе 0 значения не исследовались и показатель равен 0%.
- `needsHumanReview = true` до проверки первичного источника и идентификации точной модификации.
- «Конфликты» = «не проверены» до сопоставления значений; это не означает, что конфликтов нет.
- PR создаётся на одну модификацию. На этапе 0 PR на технические данные не создавались.

## Обнаруженные пробелы и дубли каталога

- В каталоге обнаружено 38 записей Toyota/Mitsubishi при повторном учёте разных ID; часть записей описывает одно и то же поколение/кузов. Сохранять отдельные ID в очереди до отдельного решения о дедупликации.
- Mitsubishi L200, Mitsubishi ASX и Toyota Land Cruiser 200 не найдены в текущем наборе записей `vehicleCatalog.ts` после импорта расширений. Их нельзя включить в работу по данным, пока не добавлены модели в отдельном согласованном изменении.
- Даты/кузова выше — только метаданные текущего каталога, а не независимо подтверждённые годы производства. Их проверка — часть следующего этапа.
- Сначала пилот: Outlander II / CW5W / 4B12. Нужны точный рынок и диапазон модельных лет до подбора руководства.
