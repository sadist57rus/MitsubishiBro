# Automotive logo assets

Bundled SVGs are stored locally so the brand picker works offline.

Sources:
- Simple Icons project (CC0 icon set): https://github.com/simple-icons/simple-icons — Mitsubishi, Toyota, Nissan, Subaru, Honda, Mazda, Infiniti.
- Curated car-logo SVG collection sourced from Wikimedia Commons: https://github.com/diegojasso/car-logos-SVG — Lexus.
- VehicleSpecs brand-logo collection: https://github.com/vehiclespecs/brand-logos — Suzuki, Daihatsu, Isuzu.

The logos are used only to identify vehicle makes. Trademarks belong to their respective owners. These third-party collections are not a substitute for official brand asset approval. Some manufacturers have updated brand marks in 2025–2026; before public/commercial release, compare every bundled file with the OEM brand newsroom and replace any asset that is not the current approved mark. Honda announced a refreshed H mark in January 2026 for new-generation models from 2027 onward.
